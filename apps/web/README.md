# Frontend App

Owner: Alex

This folder contains the Next.js dashboard for property managers.

Write here for:

- Dashboard routes
- React components
- UI state
- Frontend API clients
- Frontend tests

Do not write here for:

- Backend business logic
- Database access
- Provider SDK calls for Twilio, LiveKit, Gemini, Whisper, VibeVoice, calendar, or email
- Secrets

Shared contracts should come from `packages/shared` or `docs/contracts`.
