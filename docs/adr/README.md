# Architecture Decision Records

Use this folder for architecture decision records.

Create an ADR before:

- Replacing a locked provider
- Adding a new major tool
- Changing folder ownership
- Changing the voice-to-backend contract pattern
- Enabling call recording
- Adding PMS or CRM integrations

Suggested format:

```text
# ADR-000: Decision Title

Date:
Status:

## Context

## Options

## Decision

## Consequences

## Rollback Plan
```
